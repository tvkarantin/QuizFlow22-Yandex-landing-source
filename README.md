# Поток — исходники главной landing-страницы

Это точечное извлечение главной страницы из репозитория QuizFlow22-Yandex для передачи на доработку. Содержимое исходников сохранено без переписывания.

## Главная точка входа

- `components/LandingPage.tsx` — композиция всей страницы и интерактивная галерея опубликованных квизов.
- `src/router/routes/landing.tsx` — маршрут `/`, который подключает страницу.

## Блоки страницы

- `components/landing/FlowStory.tsx` + `storyData.ts` + `flow-story.css` — первый экран с прокручиваемым Canvas/React Flow и интерактивным примером сценария.
- `components/landing/PotokHeader.tsx` — шапка и навигация.
- `components/landing/StudioSections.tsx` + `studio-sections.css` — блоки «Возможности», «Лаборатория сценариев», «От замысла к запуску», «Об авторе», финальный CTA и footer.
- `components/landing/LandingPricingSection.tsx` — тарифы.
- `components/customNodes/*` — узлы React Flow, используемые Canvas на первом экране.

## Что ещё положено в архив

Положены только локальные исходники и минимальные локальные зависимости, которые импортируются этими блоками: типы, stores, API/auth-адаптеры, pricing labels, SEO-текст и `AuthModal`. Статические ресурсы находятся в `public/assets/landing/`. `node_modules`, `.git`, backend и остальные страницы приложения не включены. Файл маршрута оставлен для контекста и ссылается на родительский `publicShell`, который намеренно не входит в извлечение.

Для Tailwind-классов добавлены `index.css` и `tailwind.config.js`; `package.json` сохранён как справочник зависимостей исходного проекта. Внешняя фотография автора остаётся внешним URL, как в оригинальном коде.

Архив предназначен для передачи другой нейросети как исходный материал; для запуска в составе полного проекта потребуется вернуть эти файлы в исходную структуру репозитория.

> Публичная копия: персональный email и регистрационный идентификатор в footer заменены placeholders; исходный архив с оригинальными значениями остаётся локальным.
